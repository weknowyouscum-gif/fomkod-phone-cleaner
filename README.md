# Очистка телефона: ФомКод

Нативное Android-приложение для очистки телефона, адаптированное для пожилых людей.

- **Автор:** Фомин Евгений Андреевич
- **Бренд:** ФомКод
- **Package:** `ru.fomkod.cleaner`
- **Технологии:** Kotlin, Jetpack Compose, Material 3, WorkManager, Yandex Mobile Ads

## Сборка

APK собирается автоматически через GitHub Actions при каждом push в `main`.

Готовый APK будет доступен в Artifacts под именем `FomKod-Cleaner-APK`.

## Функции

- Простая очистка (без рекламы)
- Полная очистка с поиском дубликатов (с Rewarded Ad или бесплатно без интернета)
- Еженедельные напоминания
- Крупный шрифт и высокий контраст для удобства пожилых людей

Бесплатное социальное приложение. Экосистема ФомКод.
